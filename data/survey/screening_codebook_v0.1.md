# Paper 1 제목·초록 선별 코드북 v0.1

**상태:** 2026-10-12 착수용 훈련 초안. 책임저자·검토자 2인이 10/19–10/23 파일럿 뒤 버전 고정. [전체 실행계획](../paper1_실행계획_2026-10-12.md)의 PCC·SOP를 따른다.

## 입력 규칙

- 각 검토자는 배포받은 **별도** `reviewer_1.csv` 또는 `reviewer_2.csv`만 수정한다. `record_id`·제목·초록 등 출처 열은 수정하지 않는다.
- `decision`: `include`, `exclude`, `uncertain` 중 하나. 비어 있으면 미판정이다.
- `exclude`에는 아래 코드 한 개를 `exclusion_reason`에 쓴다. 애매하면 `uncertain`과 `note`를 쓴다.
- 초록이 없다는 사실 자체는 제외 사유가 아니다. 제목만으로 사람의 작업조건·OSH 연관성이 명백히 없을 때만 제외한다.

| 코드 | 적용 기준 | 경계 사례 처리 |
|---|---|---|
| `wrong_population` | 근로자/직무 모사 인간이 아닌 소비자·환자·학생만 대상 | 의료 종사자 업무라면 유지 |
| `no_algorithmic_work_condition` | 알고리즘 결정이 근로자 작업조건을 바꾸거나 그 조건을 측정/조작하지 않음 | AI가 업무 배정·감시·속도 결정에 관여하면 유지 |
| `no_worker_response_osh_control` | 근로자 반응, OSH 관련 결과, 통제 중 아무것도 없음 | 작업량·피로·재량·안전행동은 유지 |
| `technical_only` | 로봇 경로·충돌 회피·처리량 등 기술 지표만 보고 | 인간 참여자의 작업량/피로/안전 결과가 있으면 유지 |
| `non_empirical` | 원저 자료 없는 리뷰·이론·사설·지침 | **배경/인접 리뷰 목록에는 별도 기록**; 선행 리뷰 대조에서 삭제하지 않음 |
| `outside_date` | 프로토콜에 잠근 출판연도 밖 | 온라인/인쇄 연도 불일치는 `uncertain`으로 중재 |
| `duplicate_report` | 같은 연구의 중복 보고임이 확인됨 | 제목·초록 단계에서는 가능한 한 `uncertain`; 전문에서 study ID로 연결 |

**포함 후보 예:** 일반 고용 근로자의 알고리즘 일정 결정과 피로/스트레스; 플랫폼 배달의 알고리즘 압박과 위험 운전; HRC 배정 방식의 인간 작업량/피로 실험; 수정권·사전 통지의 인간 대상 평가.

**제외 후보 예:** 인간 자료 없이 로봇 충돌 확률만 낮춘 시뮬레이션; 환자 진단 AI의 정확도; 노동시장 일자리 수만 예측한 논문.

## 파일럿·합의

AM/HRC, 초록 있음/없음이 섞인 동일 50–100건을 두 사람이 독립 판정한다. 중재자는 합의 전에 원자료의 일치율, 각 배제 코드별 불일치, 애매한 예시를 기록한다. 모호한 기준을 수정하면 코드북 버전과 적용 시작일을 기록하고 영향을 받은 기존 판정을 두 사람이 다시 본다. 85% 또는 AC1 0.80 같은 수치를 근거 없는 절대 통과 기준으로 사용하지 않는다. 두 판정이 끝난 뒤에만 합의 파일을 만든다.

## 전문 단계 추가 사유

`full_text_unavailable`은 도서관·저자 연락·공개본 탐색을 기록한 뒤 사용한다. 전문에서는 페이지/표 위치와 주된 제외 사유를 기록한다. 같은 연구의 다른 보고서는 `study_id`를 공유하고 보고서별 `report_id`를 유지한다.
