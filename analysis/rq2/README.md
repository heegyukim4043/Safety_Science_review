# RQ2 starter kit: operationalization and measurement

**Status:** planning only; no included-study results. **Owner:** RQ2_LEAD. **Branch:** `analysis/rq2-measurement`. **Tasks:** T30 (RQ analysis), T29 (framework coordination); independent coding specification: T18. **Review:** RQ1_LEAD and DATA, with a different reviewer if both leads are the same person.

## Question and scope

How have exposures been measured in terms of unit, dose/intensity, frequency, variability, time window, reversibility, and worker control, and what measurement properties and gaps are reported?

Own perceived-exposure instruments, event logs, observation/sensors and experimental manipulations as distinct measurement approaches. Exposure operationalization, measurement validation and exposure-outcome support are different axes. The proposed L0-L3 description remains a codebook decision; it is not an eligibility or quality score.

## Inputs and keywords

Use the approved registry/evidence links after S5. Fields include exposure construct/unit/source/time window, frequency/intensity/duration/variability, dose definition, advance notice/override/reversibility, measurement reliability/validity/invariance and source locator. Use the [framework template](../../templates/measurement_framework.csv) for the integrated candidate framework with all leads.

Existing-query terms: exposure; measur*; questionnaire; scale; log*; sensor*. Proposed coverage prompts: validation; reliability; recall period; variability; reversibility; dose/intensity. Measurement searches: P5_MEASURE, S5_MEASURE, W5_MEASURE, plus common AM/HRC retrieval. See [RQ assignments](../../tracking/rq_assignments.csv).

## Deliverables and checks

- `measurement_matrix.csv`: construct, instrument/source, analysis unit/time, quantified dose, reliability/validity/invariance, population/context and evidence IDs.
- `measurement_gaps.csv`: absent units/windows/validation and methodological implications, preserving missing versus not applicable.
- `results.md`: source-located measurement synthesis, comparability limits and candidate future metrics.
- `handoff.md`: input freeze, denominators, commands, cross-review and integration requirements using the [template](../HANDOFF_TEMPLATE.md).

Verify scale/sample details against full texts. Do not treat reported scale validity as proof of OSH causation. RQ1 supplies construct definitions, RQ3 supplies response/support gaps, and RQ4 supplies modifiable controls; PI approves the integrated framework. Later Delphi/experiment variables are proposed, not validated by this review alone.
